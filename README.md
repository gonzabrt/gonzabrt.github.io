# Brito Gonzalo — sitio personal

Sitio estático creado con HTML, CSS y JavaScript, preparado para GitHub Pages.

## Publicar en GitHub Pages

1. Creá un repositorio público llamado `gonzabrt.github.io` en tu cuenta de GitHub.
2. Subí `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. En GitHub, abrí **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Seleccioná la rama `main` y la carpeta `/ (root)`, y guardá.
6. Esperá unos minutos. La web debería quedar en `https://gonzabrt.github.io/`.

Revisá los datos de contacto y el contenido antes de publicar.
